# Contributing

This repository hosts public documentation, issue tracking, and release assets; it does not contain QFlex runtime source code. Community contributions here use GitHub Issues for bug reports and feature requests.

## Report a bug

Use the [bug report form](https://github.com/whackur/qflex/issues/new?template=bug_report.yml). Include the QFlex release version, your runtime environment, minimal reproduction steps, and the expected and observed results. Do not post credentials, cookies, tokens, or private page content.

## Request a feature

Use the [feature request form](https://github.com/whackur/qflex/issues/new?template=feature_request.yml). Describe the user goal, the behavior you expect, and an example that would help maintainers evaluate the request.

## Pull requests

This repository uses an issue-only community workflow and does not accept code pull requests. Project maintainers manage its documentation and release assets.
